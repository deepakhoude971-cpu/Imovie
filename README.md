# IMovies - Online Movie Ticket Booking Platform

A full-stack MERN (MongoDB, Express.js, React.js, Node.js) web application that allows users to browse movies, select showtimes, and reserve seats with real-time availability tracking.

## Tech Stack
- **Frontend:** React.js, Bootstrap, Axios
- **Backend:** Node.js, Express.js, JWT Authentication
- **Database:** MongoDB

## Key Features
- Secure User Registration & Login (JWT)
- Movie Browsing & Showtime Selection
- Interactive Real-Time Seat Booking
- User Booking History Management
